# Tic Tac Toe 🎮

A simple and interactive Tic Tac Toe game built to practice programming logic, user interaction, and game development fundamentals. This project allows two players to play against each other in a fun and easy-to-use environment.

## Features

* Two-player gameplay
* Win and draw detection
* Interactive game board
* Simple and user-friendly interface
* Restart game functionality

## Tech Stack

* HTML
* CSS
* Javascript

## Purpose

This project was created to strengthen problem-solving skills, game logic implementation, and understanding of conditions, loops, and functions.

## How to Play

* Run the game
* Player 1 chooses **X**
* Player 2 chooses **O**
* Take turns marking spaces on the board
* First player to align three symbols wins
* If all spaces are filled without a winner, the game ends in a draw

## Game Rules

* Players can only mark empty spaces
* Turns alternate between players
* Winning combinations include rows, columns, and diagonals
